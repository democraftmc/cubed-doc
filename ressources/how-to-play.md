# 🎟 Comment Jouer
Vous avez finalement décidé de rejoindre **DEMOCRAFT** ! Celon moi, c'est vraiment la meilleur décision de toute votre existence, mais passons

## ✈️ Rejoindre le serveur
### 💻 Sur Java Edition

1. Ouvrez minecraft sur n'importe quelle version entre la 1.20 et la 1.21
2. Cliquez sur le bouton `multijoueur` 
3. Cliquez sur `ajouter un serveur`. Choisissez le nom que vous souhaitez, entrez <span style="color: red; font-weight: 900;">play.democraft.fr</span> comme adresse du serveur et cliquez sur le boutton `Pack de Ressource` jusqu'à qu'il soit écrit `Activé`.
5. Validez ensuite votre sélection. Vous devriez voir DEMOCRAFT apparaître dans la liste de vos serveur. Cliquez ensuite dessus. Attendez un peu, et vous devriez y être ! 
### 🕹 Sur Bedrock Edition

{% hint style="info" %}
**On console, and additional tweak is required**

You cannot natively add custom server to console edition of Minecraft. You have to edit your DNS settings to allow it. This is documented in OEKZBBDKZ, but keep in mind that it's writed in french
{% endhint %}
