
# 🎟 Comment Jouer

Vous avez finalement décidé de rejoindre **DEMOCRAFT** ! Celon moi, c'est vraiment la meilleur décision de toute votre existence, mais passons

## ✈️ Rejoindre le serveur
### 💻 Sur Java Edition

1. Ouvrez minecraft sur n'importe quelle version entre la 1.20 et la 1.21
2. Cliquez sur le bouton `multijoueur` 
3. Cliquez sur `ajouter un serveur`. Choisissez le nom que vous souhaitez, entrez <mark style="color: red;" >play.democraft.fr</mark>comme adresse du serveur et cliquez sur le boutton `Pack de Ressource` jusqu'à qu'il soit écrit `Activé`.
5. Validez ensuite votre sélection. Vous devriez voir DEMOCRAFT apparaître dans la liste de vos serveur. Cliquez ensuite dessus. Attendez un peu, et vous devriez y être ! 
### 🕹 Sur Bedrock Edition

{% hint style="warning" %}
**Sur console, une étape supplémentaire est nécessaire**

Vous ne pouvez pas nativement ajouter un serveur externe sur bedrock. Vous devez d'abord modifier vos paramètres DNS, celon votre console. Un tutoriel est disponible [sur notre wiki](https://wiki.democraft.fr/accueil/connexion/bedrock-edition).
{% endhint %}

1. Cliquez sur `jouer`, puis sur `serveur`
2. Cherchez un boutton `ajouter un serveur` à la fin de la liste des serveur. Rentrez comme adresse du serveur <mark style="color: red;">bedrock.democraft.fr</mark>. Pour le port du serveur, nous utilisons celui par défaut, `19132`. Comme sur Java, vous pouvez appeler le serveur comme vous le souhaitez.
3. Validez votre sélection. Mojang va peux être vous prévenir que notre serveur n'est pas certifié, mais dites lui que vous êtes sur de jouer. Vous pouvez ensuite cliquer sur le serveur, et un bouton `connexion` va apparaître. Cliquez dessus, acceptez notre ressource pack, attendez un peu et ça deverais être bon !
